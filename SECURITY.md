# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in JMComic QQ Bot, please **do not open a public issue**.

Instead, send a private report via GitHub's **Security Advisories** feature:

1. Go to https://github.com/lujih/JMComic-QQ-Bot/security/advisories
2. Click **"New draft security advisory"**
3. Fill in the details

We aim to respond within 48 hours.

## Scope

- QQ bot authentication and session handling
- Credential leakage in logs or Docker build output
- Unauthorized access to NapCat WebUI

## Out of Scope

- The underlying jmcomic library (report upstream)
- HF Spaces infrastructure (report to Hugging Face)
- NapCatQQ project (report upstream)
